**初心者向けサーバー／Linux／Docker 学習ノート（全29本）**を  
設計・生成・管理するための基盤です。

- 👉 [全ノートINDEX（29本）](./final_package/INDEX.md)

---

## 🧠 設計思想
- 初心者の「怖い・分からない」を先に潰す
- 無料＝概念理解／不安解消
- 有料＝手順・コマンド・地雷マップ・復旧ルート
- 失敗前提で安全に戻れる設計
