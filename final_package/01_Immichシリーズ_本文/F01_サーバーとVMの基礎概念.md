## 本編

### 1. 「サーバー」って何をする存在？

「サーバー」と聞くと、どこか大きな機械が並んだデータセンターをイメージするかもしれません。でも本質はシンプルです。**サーバーとは「何かを提供する役割を持つコンピューター」**のことです。

わかりやすい例えで言うと、レストランの「ウェイター（給仕係）」に近い存在です。お客さん（あなたのブラウザやスマートフォン）からリクエストを受け取り、必要なものを返してくれる役割を担います。普段使っているウェブサイトも、どこかのサーバーがあなたのリクエストに答えて画面を表示しています。

このシリーズでは「自分のPC内にサーバーを作る」ことを目標にします。Google や Dropbox のような企業のサーバーを借りずに、自分でデータを管理できる環境を手元に持つのがゴールです。

---

### 2. VMとは「PCの中に作る、もう1台のPC」

仮想マシン（VM / Virtual Machine）とは、ソフトウェアの力を使って「コンピューターの中にもう1台のコンピューターを作り出す」技術です。言葉だけ聞くと難しそうですが、例えで考えると一気にイメージしやすくなります。

**「部屋の中に組み立て式の小屋を建てる」**をイメージしてください。部屋（あなたのPC）はそのままで、その中に独立した小屋（VM）を建てます。小屋の中で何かを壊しても、部屋そのものは傷つきません。VMも同じで、**VM内で何かを失敗しても、あなたの普段使いのPCには一切影響がありません。**

この「本物のPCへの影響ゼロ」という性質が、このシリーズでVMを使う最大の理由です。

---

### 3. なぜVMは「失敗しても安全」なのか

VMが安全な理由はもう1つあります。**スナップショット**という機能です。

スナップショットとは、VMの状態をその瞬間に「写真を撮るように保存」する機能です。ゲームのセーブデータに近いイメージで、「ここまでは成功している」という時点をいつでも保存できます。もし設定を間違えたり、何かが壊れたりしても、そのセーブデータに戻すだけです。何度でもやり直せます。

「コマンドを打ち間違えてPCが壊れたら……」という不安は、VMとスナップショットの組み合わせでほぼ解消されます。このシリーズを通じて、「詰まったら戻せばいい」という感覚が自然と身につきます。

---

### 4. クラウドと自前サーバー、何が違うの？

Google フォトや Dropbox のようなクラウドサービスは便利ですが、「企業のサーバーにデータを預ける」という仕組みです。月額料金・データの所在・サービス終了リスク、という側面が常にあります。

自前サーバーはこれを「自分のPC」で代替します。データは手元に残り、月額費用は原則かかりません。最初の構築に手間はかかりますが、一度作ればずっと使えます。どちらが正解ではなく、「自分でやってみたい」と思った方に向けて、このシリーズは安全に始める方法を案内します。

---

### 5. 有料ノートP01では何をするか（予告）

無料ノートF01〜F04で概念を理解したあと、有料ノートでは実際に手を動かします。

```
有料ノート P01「VM構築手順（初心者向け）」では：
  ・VMソフトのインストール
  ・Ubuntu Server の起動
  ・スナップショットの取得
  ・詰まりやすい箇所の地雷マップ
  ・復旧ルート
```

コマンドや推奨設定値、画面操作の手順がすべて揃った状態でお届けします。「概念を知った上で手順書を見る」と理解のスピードが格段に上がります。

## 用語集

| 用語 | かんたん説明 |
|------|-------------|
| サーバー | リクエストに対して何かを返す役割を持つコンピューター |
| 仮想マシン（VM） | ソフトウェアで作った「PCの中のもう1台のPC」 |
| ホストPC | VMを動かしているあなたの実際のPC |
| ゲストOS | VM内で動いているOS（このシリーズではUbuntu Server） |
| スナップショット | VMの状態をその瞬間に保存する機能。ゲームのセーブデータに相当 |
| Ubuntu Server | Linuxベースのサーバー向けOS。無料で使える |
| Docker | アプリを「箱（コンテナ）」にまとめて動かす仕組み |
| クラウド | 企業のサーバーを借りてデータを預けるサービス（例：Google フォト） |
| オープンソース | コードが公開されており、無料で利用できるソフトウェア |
