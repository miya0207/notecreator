# Immich構築とチェックポイント

> **ServerStart｜有料ノート P03 / P03（最終回）**

---

## このノートでできるようになること

- docker-composeを使ってImmichを起動できる
- ブラウザからImmichのログイン画面を表示できる
- バックアップの考え方と最低限の実装を理解できる
- 起動しないときのトラブルを自分で切り分けられる

---

## 想定読者 / 前提知識

- 有料ノートP02を完了し、`docker compose version` が表示できる方
- スナップショット「Docker導入済み」が取得済みの方
- Immichとは何かを知っている方（無料ノートF04で確認できます）

## 全体像

このノートで行う作業の流れです。

```
① 作業前スナップショットを取得する
    ↓
② 作業ディレクトリを作成する
    ↓
③ Immich公式ファイル（docker-compose.yml / .env）を取得する
    ↓
④ .envファイルを最低限編集する
    ↓
⑤ コンテナを起動する
    ↓
⑥ ブラウザからアクセスして動作確認する
    ↓
⑦ バックアップの仕組みを設定する
    ↓
⑧ スナップショットを取得する ← Immich起動済みの安全地点
```

## 本編

### 1. 作業前のスナップショット取得

作業開始前に必ずスナップショットを取得してください。

```
操作: VirtualBox → スナップショット → スナップショットの取得
名前: 「Immich構築前」
```

---

### 2. 作業ディレクトリの作成

Immichの設定ファイルをまとめて置く専用フォルダを作成します。

```bash
# ホームディレクトリ直下に immich フォルダを作成
mkdir ~/immich
cd ~/immich
```

> 💡 `~` はホームディレクトリの省略記法です。`/home/ユーザー名/` と同じ場所を指します。

---

### 3. Immich公式ファイルの取得

Immichの公式ドキュメントが提供するファイル一式を取得します。

```bash
# docker-compose.yml を取得
wget -O docker-compose.yml https://github.com/immich-app/immich/releases/latest/download/docker-compose.yml

# .env（環境変数設定ファイル）を取得
wget -O .env https://github.com/immich-app/immich/releases/latest/download/example.env

# 取得確認
ls -la
# docker-compose.yml と .env の2ファイルが表示されればOK
```

---

### 4. .envファイルの編集

`.env` ファイルに保存場所の設定をします。ここだけ編集すれば最低限動きます。

```bash
# .envファイルを開く
nano .env
```

```bash
# 以下の2行を確認・編集する（他の行はそのままでOK）

UPLOAD_LOCATION=./library
# → 写真の保存先ディレクトリ。デフォルトのままでOK

DB_PASSWORD=postgres
# → データベースのパスワード。任意の文字列に変更推奨
#   例: DB_PASSWORD=ServerStart2024secure
```

```
# nano の操作方法:
# 編集後: Ctrl + O → Enter（保存）
# 終了  : Ctrl + X
```

> ⚠️ `.env` ファイルにはパスワードが含まれます。GitHubなど外部に公開しないよう注意してください。

---

### 5. コンテナの起動

```bash
# バックグラウンドでImmichを起動
docker compose up -d

# 起動状態を確認（全コンテナが "Up" になるまで1〜3分かかることがある）
docker compose ps

# ログを確認（エラーが出ていないか確認）
docker compose logs --tail=50
```

すべてのコンテナが `Up` と表示されれば起動成功です。

---

### 6. ブラウザからの動作確認

ホストPC（あなたのPC）のブラウザから以下のURLにアクセスします。

```
http://VMのIPアドレス:2283

例: http://192.168.56.10:2283
```

> 💡 VMのIPアドレスは `ip addr show` で確認できます（P02で固定した場合はその値を使います）。

Immichのログイン画面（または初回アカウント作成画面）が表示されれば **構築成功** です。おめでとうございます！

**初回アカウント作成後の確認ポイント：**

```
✅ ログイン画面が表示される
✅ アカウントを作成してログインできる
✅ 写真のアップロードができる
✅ スマートフォンのImmichアプリから同じURLで接続できる（LAN内）
```

---

### 7. バックアップの考え方と最低限の実装

Immichのデータは2種類を守る必要があります。

```
① 設定ファイル群
   ~/immich/docker-compose.yml
   ~/immich/.env

② データボリューム（写真・データベース）
   docker volume ls で確認できる
```

**設定ファイルのバックアップ（最低限）：**

```bash
# 設定ファイルをtarで圧縮保存
tar czf ~/backup_config_$(date +%Y%m%d).tar.gz \
  ~/immich/docker-compose.yml ~/immich/.env

# バックアップされたか確認
ls ~/backup_config_*.tar.gz
```

> ⚠️ バックアップファイルは可能な限りVM外（USBや別のPCなど）にも保存してください。VMが壊れた場合に備えるためです。

**データボリュームのバックアップ（基本方針）：**

```bash
# Immichが使っているボリュームを確認
docker volume ls | grep immich
```

詳細なボリュームバックアップ手順は、サーバーの用途と規模によって最適解が変わります。運用が安定してきたタイミングで、定期的なバックアップスクリプトの設定を検討してください。

```
外部公開に必要な要素（参考）:

```

これらはImmichを安定して使いこなせるようになってから、別途学習することをおすすめします。


## よくある詰まりと対処

### 地雷マップ

| 詰まりパターン | 原因の可能性 | 対処手順 |
|--------------|------------|---------|
| コンテナがすぐ `Exited` になる | .envの設定ミス | `docker compose logs --tail=50` でエラー内容を確認する |
| ブラウザでアクセスできない | IPアドレスが間違っている | `ip addr show` でIPを再確認する |
| ブラウザでアクセスできない | ポート2283が使われていない | `docker compose ps` でポートのマッピングを確認する |
| ブラウザでアクセスできない | ファイアウォールが2283をブロック | `sudo ufw allow 2283/tcp && sudo ufw reload` を実行する |
| 写真がアップロードできない | ディレクトリの権限不足 | `ls -la ~/immich/library/` で権限を確認し、`sudo chmod -R 755 ~/immich/library/` を実行する |
| コンテナのメモリが不足 | VMのメモリが少ない | VMを停止してVirtualBox設定でメモリを4096MBに増やす |

### トラブル時の切り分け手順

```
Step 1: コンテナの状態を確認する
  docker compose ps
  → Exited があれば次のステップへ

Step 2: ログでエラーを特定する
  docker compose logs --tail=100
  → "ERROR" または "FATAL" の行を探す

Step 3: エラーの内容で対処を判断する
  "permission denied" → 権限エラー（地雷マップ参照）
  "address already in use" → ポート競合（他のアプリが2283を使用中）
  "no space left on device" → ディスク不足（df -h で確認）

Step 4: 再起動を試みる
  docker compose down
  docker compose up -d
```

### 復旧ルート

```
【コンテナが起動しない場合】
  docker compose down
  docker compose up -d
  → それでも直らない場合はスナップショット「Immich構築前」に戻す

【設定ファイルを誤って壊した場合】
  → スナップショット「Immich構築前」に戻す
  操作: VirtualBox → スナップショット → 「Immich構築前」→ 復元
  → 手順2から再開する

【「どうしても動かない」場合】
  docker compose logs > ~/debug.log
  → 生成されたdebug.logをサポートに添付して質問する
```

## 用語集

| 用語 | かんたん説明 |
|------|-------------|
| Immich | Google フォト代替のオープンソース写真管理アプリ |
| .env ファイル | 環境変数（パスワードなどの設定値）を書くファイル |
| docker compose up -d | コンテナをバックグラウンドで起動するコマンド |
| docker compose down | コンテナを停止・削除するコマンド（データは残る） |
| docker compose ps | コンテナの動作状態を一覧表示するコマンド |
| docker compose logs | コンテナの動作ログを表示するコマンド |
| ポート2283 | ImmichがLAN内通信に使う窓口番号 |
| ufw | Ubuntuのファイアウォール管理コマンド |
| tar | ファイルをまとめて圧縮・保存するコマンド |
| リバースプロキシ | 外部アクセスを仲介するサーバー設定（外部公開時に必要） |

## 次のノートへの導線

> 🎉 **ServerStart シリーズ P03 完了！全7本のノートを制覇しました！**

おめでとうございます。「PC → VM → Ubuntu Server → Docker → Immich」という全体構成を、実際に手を動かして構築できました。

- 新しいアプリの構築ガイド

引き続きServerStartをご活用ください。
