## 本編

### 1. Ubuntu Serverとは何か

Ubuntu Server（ウブントゥ・サーバー）は、**Linuxというオープンソース（無料）のOSをサーバー用途に最適化したもの**です。世界中のウェブサービスやクラウド基盤で使われており、信頼性と実績があります。

「Linux」と聞くと取っつきにくい印象があるかもしれませんが、原理はWindowsやmacOSと同じです。コンピューターのハードウェアとアプリをつなぐ「橋渡し役」がOSの役割で、Ubuntu Serverはサーバー専用の橋渡し役です。Ubuntu Serverを使う理由は主に2つ、**無料であること**と**Dockerとの相性が良いこと**です。

---

### 2. なぜ画面（GUI）がないのか

Ubuntu Serverをインストールすると、最初から「黒い画面に文字だけ」の状態になります。WindowsのようなアイコンやGUI（グラフィカルな操作画面）がありません。これを最初に見ると多くの方が「失敗した？」と感じますが、**これが正常な状態です。**

サーバーは「ずっと動き続けること」が仕事です。GUIは見た目はわかりやすい反面、CPUとメモリをたくさん消費します。24時間365日稼働するサーバーにGUIは不要なため、最初から省いています。「余計なものを積まないことで、本業（サービスの提供）に全力を注ぐ」という設計思想です。

---

### 3. ターミナルは「コンピューターへの話しかけ方」

GUIがない代わりに使うのが**ターミナル（コマンドライン）**です。キーボードで文字を打ち込んでコンピューターに指示を出す方法で、最初は怖く見えますが、慣れると「メモに書いた指示をそのまま渡す」感覚でとても合理的です。

たとえばGUIで「フォルダを開く→ファイルを選ぶ→右クリックして削除」という3ステップが、ターミナルだと1行の命令で完結します。このシリーズで打つコマンドは最小限に絞っており、有料ノートにはコピペできる形で提供します。「意味を全部理解してから打つ」必要はありません。

---

### 4. よくある誤解を整理しよう

**誤解①「LinuxはWindowsとまったく別物で難しい」**
→ 基本的な概念（ファイル・フォルダ・権限）はWindowsと共通です。コマンドの書き方が違うだけで、やることの本質は同じです。

**誤解②「一度設定を間違えると取り返しがつかない」**
→ F01でお伝えしたスナップショット機能があるので、いつでもやり直せます。「壊れたら戻せばいい」という安心感は、このシリーズ全体の土台です。

**誤解③「英語が読めないと使えない」**
→ コマンドやエラーメッセージは英語ですが、有料ノートでよく出るエラーの意味と対処法を日本語で解説します。英語力はほぼ不要です。

## よくある詰まりと対処

> ※ 無料ノートでは「詰まりの原因カテゴリ」をお伝えします。

**「黒い画面を見るだけで頭が真っ白になる」系**
→ 最初は全員がそうです。有料ノートでは「何行目に何を打つか」を1ステップずつ案内します。打つ前に「何をしているか」の説明も入れているので、少しずつ慣れていけます。

**「ターミナルで打ち間違えてしまいそう」系**
→ 有料ノートのコマンドはすべてコピペ可能な形にしています。タイポ（打ち間違え）のリスクを最小化します。

**「LinuxとUbuntuとUbuntu Serverの違いがわからない」系**
→ Linux＝OSの種類の名前、Ubuntu＝Linuxのディストリビューション（派生版）の1つ、Ubuntu Server＝Ubuntuのサーバー向けエディション、という関係です。「Windows」「Windows 11」「Windows 11 Pro」の関係に近いイメージです。

## 用語集

| 用語 | かんたん説明 |
|------|-------------|
| Linux | 無料で使えるオープンソースのOS。サーバーで広く利用される |
| Ubuntu | Linuxの代表的なディストリビューション（派生版）の1つ |
| Ubuntu Server | UbuntuのサーバーOS版。GUIなし・軽量・Docker対応 |
| ディストリビューション | Linuxをベースに各社が配布しているOSのバリエーション |
| GUI | Graphical User Interface。アイコンや画面で操作するUI |
| ターミナル | コマンドライン操作をするためのテキスト入力画面 |
| コマンド | ターミナルに打ち込む命令文 |
| SSH | ネットワーク越しにサーバーをリモート操作する仕組み |
| ISO ファイル | OSのインストールメディアをファイル化したもの |
