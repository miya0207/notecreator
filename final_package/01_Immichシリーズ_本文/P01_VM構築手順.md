# VM構築手順（初心者向け）

> **ServerStart｜有料ノート P01 / P03**

---

## このノートでできるようになること

- 自分のPCにVMソフト（VirtualBox）をインストールできる
- Ubuntu ServerのVMを作成して起動できる
- スナップショットで安全な作業環境を整えられる
- 詰まったときに地雷マップを使って自力で対処できる

---

## 想定読者 / 前提知識

- ServerStartの無料ノートF01〜F04を読んだ方
- VM・Ubuntu Serverの概念をざっくり理解している方
- WindowsまたはMacのPCを持っている方
- コマンドライン操作は初めてでもOK（コピペで進めます）

---

## 全体像

このノートで行う作業の流れです。

```
① PCスペックを確認する
    ↓
② VirtualBoxをインストールする
    ↓
③ Ubuntu Server ISOファイルを入手する
    ↓
④ VMを作成する（スペック設定）
    ↓
⑤ Ubuntu Serverをインストールする
    ↓
⑥ ログインを確認する
    ↓
⑦ スナップショットを取得する ← ここで安全網を作る
```

---

## 本編

### 1. 作業前のPCスペック確認

VMを快適に動かすためのスペック目安を、利用スタイル別に3パターン示します。
どれが自分に当てはまるか確認してから始めましょう。

```
【パターンA：最低限動かせる構成】
  OS    : Windows 10 / macOS 12 以上
  RAM   : 8GB
  ディスク: 空き容量 30GB 以上
  CPU   : 仮想化機能（VT-x / AMD-V）対応

【パターンB：推奨構成（快適に動く）】
  OS    : Windows 11 / macOS 13 以上
  RAM   : 16GB
  ディスク: 空き容量 60GB 以上（SSD推奨）
  CPU   : 4コア以上

【パターンC：複数アプリを動かしたい場合】
  RAM   : 32GB
  ディスク: 空き容量 100GB 以上（SSD必須）
```

> 💡 自分のRAMをWindowsで確認する方法：タスクマネージャー → パフォーマンス → メモリ
> 💡 Macで確認する方法：Appleメニュー → このMacについて → メモリ

**CPUの仮想化機能について：** 多くのPCで初期状態で有効です。無効の場合はBIOS/UEFI設定から有効化します（詳細は地雷マップを参照）。

---

### 2. VirtualBoxのインストール

VirtualBoxはOracle社が無料で提供するVMソフトです。公式サイトからダウンロードします。

```
ダウンロード先: https://www.virtualbox.org/wiki/Downloads
  Windowsの場合: "Windows hosts" をクリック
  Macの場合    : "macOS / Intel hosts" または "macOS / Arm64 hosts" を選択
                 ※ M1/M2/M3 Mac は "Arm64" を選んでください
```

**インストール手順（Windows）：**

```
1. ダウンロードした .exe ファイルをダブルクリック
2. 「次へ」を数回クリック（設定はデフォルトのままでOK）
3. 「インストール」をクリック
4. 完了後、デスクトップに「Oracle VirtualBox」アイコンが表示されることを確認
```

> ⚠️ インストール中「ネットワークアダプターをリセットします」という警告が出ることがあります。数秒間インターネットが切断されるため、重要な作業中は一時停止してください。

---

### 3. Ubuntu Server ISOファイルの入手

Ubuntu Serverのインストールメディア（ISOファイル）を公式サイトから入手します。

```
ダウンロード先: https://ubuntu.com/download/server
推奨バージョン: Ubuntu Server 24.04 LTS
               （LTS＝Long Term Support。長期サポート版で安定）
ファイルサイズ: 約2GB
ファイル名例 : ubuntu-24.04.2-live-server-amd64.iso
```

> 💡 ダウンロードに数分〜十数分かかります。完了するまで次の作業を進めても構いません。

---

### 4. VMの作成

VirtualBoxを起動して、新しいVMを作成します。

```
操作: VirtualBox 起動 → 「新規（New）」ボタンをクリック

設定値（推奨）:
  名前     : ServerStart（任意）
  フォルダー: デフォルトのままでOK
  タイプ   : Linux
  バージョン: Ubuntu (64-bit)
  メモリ   : 2048 MB（パターンBなら 4096 MB 推奨）
  CPU      : 2（パターンBなら 4 推奨）
  ディスク : 30 GB（動的割り当て）
```

> 💡 メモリとCPUは後から変更できます。まず2GB/2コアで始めて、重さを感じたら増やしましょう。

---

### 5. Ubuntu Serverのインストール

VMを起動し、ISOファイルをセットしてインストールを開始します。

```
操作:
  1. 作成したVMを選択 → 「起動（Start）」
  2. ポップアップが出たらISOファイルを選択して起動
  3. インストーラーが起動する
```

**インストーラーでの重要な選択箇所：**

```
言語選択     : English（日本語はトラブルが起きやすいため）
キーボード   : Japanese / Japanese (OADG 109A)
ネットワーク : デフォルト（DHCP自動取得）のままでOK
ストレージ   : "Use an entire disk" を選択
OpenSSH     : ✅ チェックを入れる（後でリモート操作に使う）
ユーザー名  : 任意（例：serverstart）
パスワード  : 任意（必ずメモしておく）
```

> ⚠️ パスワードは後から変更できますが、設定したものを必ずメモしてください。インストール後のログインに必要です。

インストール完了後、再起動するとログインプロンプトが表示されます。設定したユーザー名とパスワードでログインできれば**インストール成功**です。

---

### 6. スナップショットの取得

ここまで成功した状態を必ず保存しておきます。

```
操作:
  1. VMを一時停止またはシャットダウン
     （VM内で: sudo shutdown now）
  2. VirtualBoxマネージャーで対象VMを右クリック
  3. 「スナップショット」→「スナップショットの取得」
  4. 名前: 「Ubuntu起動確認済み」で保存
```

> 💡 スナップショットは何個取っても構いません。作業の節目ごとに取る習慣をつけましょう。取りすぎて困ることはありません。

---

## チェックポイント

```
✅ VirtualBoxが起動し、作成したVMが一覧に表示される
✅ VMを起動するとUbuntu Serverのログインプロンプトが表示される
✅ ユーザー名とパスワードでログインできる
✅ ログイン後に画面にプロンプト（例: serverstart@ubuntu:~$）が表示される
✅ スナップショット「Ubuntu起動確認済み」が保存されている
```

## よくある詰まりと対処

### 地雷マップ

| 詰まりパターン | 原因の可能性 | 対処手順 |
|--------------|------------|---------|
| VMが起動しない・エラーが出る | CPU仮想化機能が無効 | PCを再起動 → BIOS/UEFI画面（起動時にF2/Delete押下）→ Virtualization Technology を Enabled に変更 |
| ISOを選んでも起動しない | ストレージコントローラーの設定ミス | VM設定 → ストレージ → 「光学ドライブ」にISOが割り当てられているか確認 |
| インストール後に画面が真っ暗 | グラフィック設定の問題 | VM設定 → ディスプレイ → ビデオメモリを 16MB 以上に変更 |
| ログインできない | パスワードの入力ミス（入力中は表示されない） | パスワードは画面上に何も表示されないが、実際には入力されている。ゆっくり正確に打ち直す |
| M1/M2 Mac でVMが重い | Arm版ISOを使っていない | Ubuntu Server ARM版（ubuntu-24.04-live-server-arm64.iso）を使用する |

### 復旧ルート

```
【何かおかしくなった場合】
  → スナップショット「Ubuntu起動確認済み」に戻す
  操作: VirtualBoxマネージャー → スナップショット → 該当スナップショットを選択 → 復元

【スナップショットを取る前に壊した場合】
  → VMを削除して手順4〜6をやり直す
  操作: VirtualBoxマネージャー → VMを右クリック → 削除 → 全ファイルを削除
  → ISOファイルは再ダウンロード不要（保存してあればそのまま使える）

【VirtualBoxをアンインストールしてやり直したい場合】
  → コントロールパネル（Windows）またはアプリケーションフォルダ（Mac）から削除
  → ただしVMのファイルは別フォルダに残るため、手動削除が必要
```

## 用語集

| 用語 | かんたん説明 |
|------|-------------|
| VirtualBox | Oracle社提供の無料VMソフト |
| ISO ファイル | OSのインストールメディアをファイル化したもの |
| LTS | Long Term Support。数年単位でサポートされる安定版 |
| DHCP | ネットワーク上のIPアドレスを自動で割り当てる仕組み |
| OpenSSH | ネットワーク越しにサーバーをリモート操作するためのソフト |
| スナップショット | VMの状態を保存する機能。失敗したら戻せる |
| BIOS / UEFI | PC起動時に動くファームウェア。仮想化機能の有効化に必要 |
| ログインプロンプト | OSが起動後にユーザー名・パスワードを求める画面 |
| sudo | Linux で管理者権限を一時的に使うためのコマンド接頭辞 |
