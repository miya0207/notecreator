## 本編

### 1. 作業前のスナップショット取得

作業を始める前に必ずスナップショットを取得してください。失敗してもこの時点に戻せます。

```
操作: VirtualBox → 対象VMを右クリック → スナップショット → スナップショットの取得
名前: 「CL2-P01作業前」
```

### 2. EC2へのDocker導入手順

```bash
# 作業ディレクトリを作成
mkdir ~/cl2 && cd ~/cl2

# docker-compose.yml を取得（公式ドキュメントのURLを参照）
wget -O docker-compose.yml [公式URL]
wget -O .env [公式URL]

# コンテナを起動
docker compose up -d

# 起動確認
docker compose ps
docker compose logs --tail=50
```

> ⚠️ .env ファイルにはパスワードが含まれます。外部に公開しないよう注意してください。

### 3. セキュリティグループのポート設定

この手順では「セキュリティグループのポート設定」を実施します。
以下のコマンドをSSH接続後のターミナルで順番に実行してください。

```bash
# セキュリティグループのポート設定 の実施
sudo apt update
# ↑ まずシステムを最新状態にする（毎回の作業前に実行する習慣をつけましょう）
```

> 💡 コマンドの意味がわからなくても、コピペで進められます。意味は使いながら覚えましょう。

### 4. チェックポイント

各ステップ完了後に以下を確認してください。

```
✅ EC2上でdocker compose upができる
✅ コンテナをEC2で起動できる
```

### 5. 地雷マップ

| 詰まりパターン | 原因の可能性 | 対処手順 |
|--------------|------------|---------|
| コマンドが見つからないエラー | インストール未完了 | インストール手順を最初からやり直す |
| 権限エラー（permission denied） | sudo が必要 | コマンド先頭に sudo を付けて再実行する |
| ネットワークエラー | VM内のインターネット接続なし | VirtualBoxのネットワーク設定がNATになっているか確認する |
| ブラウザからアクセスできない | IPアドレスまたはポートの誤り | `ip addr show` でIPを再確認する |
| コンテナがすぐExitedになる | 設定ファイルのミス | `docker compose logs` でエラー内容を確認する |

### 6. 復旧ルート

```
【何か失敗した場合の戻し方】
  → スナップショット「CL2-P01作業前」に戻す
  操作: VirtualBox → スナップショット → 該当スナップショット → 復元

【コンテナが起動しない場合】
  docker compose down
  docker compose up -d

【どうしても解決しない場合】
  docker compose logs > ~/debug.log
  → debug.log をサポートに添付して質問する
```

### 7. 完了スナップショットの取得

すべての作業が完了したら、この状態を保存します。

```bash
sudo shutdown now
```
```
操作: VirtualBox → スナップショット → スナップショットの取得
名前: 「CL2-P01完了」
```

## よくある詰まりと対処

**「コマンドを打ったらエラーが出た」系**
→ まず `docker compose logs --tail=50` でログを確認。「ERROR」の行を探してください。

**「手順通りにやったのに動かない」系**
→ スナップショットに戻して最初からやり直すのが最短解です。ISOファイルの再ダウンロードは不要です。

**「ブラウザからアクセスできない」系**
→ VMのIPアドレスとポート番号を `ip addr show` と `docker compose ps` で再確認してください。

## 用語集

| 用語 | かんたん説明 |
|------|-------------|
| docker compose up -d | コンテナをバックグラウンドで起動するコマンド |
| docker compose down | コンテナを停止・削除するコマンド（データは残る） |
| docker compose ps | コンテナの起動状態を一覧表示するコマンド |
| docker compose logs | コンテナの動作ログを表示するコマンド |
| sudo | 管理者権限でコマンドを実行する接頭辞 |
| apt | Ubuntuのパッケージ管理コマンド |
| スナップショット | VMの状態を保存する機能。失敗したら戻せる |
| .env ファイル | パスワードなどの設定値を書くファイル |
| systemctl | Linuxのサービス（デーモン）を管理するコマンド |
